## Project Overview
GregSweeper, modern Minesweeper game built with vanilla JavaScript (ES6 modules). No framework, no bundler, no package.json. Deployed on GitHub Pages.

## Development

**Local server:** `python -m http.server 8080` (or `GregSweeper.bat`). No build step for the shipped app; Firebase SDK via CDN. The root `package.json` is dev/CI tooling ONLY (Playwright e2e + `node --test`): it must never gain a runtime `dependencies` block, the deployed app imports nothing from `node_modules`, and `node_modules` never deploys.

**Unit tests:** pure-logic regression suite in `test/` (`node --test test/*.test.mjs`, dependency-free), run by `.github/workflows/test.yml` on every push/PR to main/test; keep it green before merging. Each pinned behavior names its incident in the test header with the pinning case prefixed `REGRESSION:` (greppable). Notable standing gates: the tiling certification tests (one per tiling over frozen fixtures in `test/fixtures/`, each with a rectangular control that must be UNSOLVABLE, stalling on click 1, or the gate is vacuous), the import-smoke gate (every `src/{logic,firebase,state,storage,game,ui,audio}` module evaluates headless via `test/domShim.mjs`), and the icon-coverage source scan (any `\p{Extended_Pictographic}` emoji in `src/**/*.js` or `index.html` must be classified in `src/ui/iconCoverage.js`'s `ICON_STATUS`; `src/ui/themeManager.js` is excluded, validated by spriteChain instead).

**Browser e2e:** Playwright harness in `tests/e2e/` (`npm install` once, `npm run test:e2e`), served by the dependency-free `scripts/serve-static.mjs` (port is argv, default 8123). EVERY spec entry must include `isTest=1`: plain localhost is NOT a test environment, and an entry without it boots fully ungated against production. `tests/e2e/smoke.spec.mjs` is the boot gate: zero console errors and zero `identitytoolkit accounts:signUp` requests per entry point. **Any spec that measures GEOMETRY must call `settleAnimations(page)` (`tests/e2e/helpers.mjs`) before every measurement**; sampling mid-animation is the flake class, and the fix is never a wider tolerance. `?level=<N>` and `?dailyShape=` deep links are TEST ENVIRONMENTS ONLY and practice-gated end to end (`state.isLevelPractice`), because `/test/` shares the origin's localStorage with prod.

**Regression policy:** every bug-fix PR adds a test that FAILS before the fix, at the cheapest layer that can catch it: pure helper > import-smoke > boot-smoke > e2e journey. DOM-coupled decisions get EXTRACTED into pure helpers (the `moltDay` / `resumeEligibility` / `gameoverPlan` pattern); DOM behavior a helper cannot reach is call-tested headless via `test/domShim.mjs`. A static `tsc --checkJs` gate (`npm run typecheck`, `jsconfig.json`) covers a curated set of pure `src/logic` modules. Firebase rules ENFORCEMENT tests (emulator) are deliberately deferred; the structure-assertion tests catch the highest-frequency class.

**Deploy:** push to `main` triggers GitHub Pages via `.github/workflows/deploy-pages.yml` (main at `/`, the `test` branch at `/test/` with an orange banner and `isTestEnvironment()` write-gating). Failed deploys SELF-HEAL: `retry-pages-deploy.yml` re-dispatches with an escalating backoff (decision logic pure in `scripts/pages-deploy-retry.mjs`, pinned by `test/pagesDeployRetry.test.mjs` including the workflow-name coupling). After push, bump `CACHE_NAME` in `sw.js`: **its `MAJOR.MINOR` must always equal `CURRENT_VERSION` in `main.js`**, and `N` is the per-deploy counter, reset to 0 on a version bump.

**A MINOR bump is a player-facing release, not a deploy counter** (his ruling 2026-07-18): bump `CURRENT_VERSION` only for something a player can feel, always paired with a What's New entry worth the interruption; infrastructure rides the `N` counter indefinitely. Production serves at **`gregsweeper.com`** (Porkbun ALIAS to `christopherwells.github.io`, HTTPS via GitHub).

## Modifier Load-Bearing Filter (generation)

Beyond solvability, every generation path requires each non-exempt modifier on a board to contribute at least one needed deduction. `findDecorativeGimmicks` in `boardSolver.js` strips one gimmick type's info at a time and re-solves; still-solvable means decorative, and the candidate is rejected. The contracts:

- **Exempt:** mystery and worm (they only remove or delay information, so they can never contribute; worm's exemption is by omission from `TESTABLE_GIMMICK_TYPES`), walls and locked (structural, stripping them would invalidate the numbers). **Testable:** sonar, compass, wormhole, liar, mirror.
- **Per-type, not per-cell**, deliberately: a board with three sonar cells passes if sonar as a type contributed.
- A modifier "contributes" when stripping it makes the board unsolvable, raises the technique level, or adds >= 2 clicks (`_gimmickContributes`; the 2-click threshold avoids penalizing incidental savings).
- **Fallback:** precompute falls back to the highest-scoring solvable candidate; the daily/weekly play paths relax after `LOAD_BEARING_BUDGET` = 25 attempts. **The Challenge ladder is the exception: STRICT, no relax-to-ship** (his ruling).
- **The counterfactual is RECORDED, not discarded** (2026-07-30): `computeContributionFeatures` (boardSolver.js) keeps per-type `<g>Required` (0/1) and `<g>ClicksSaved` features for the five testable types. There is deliberately NO technique-delta output (his ruling). A fit must read the pair jointly (ClicksSaved reports 0 when required).

## The No-Guess Contract (status per 2026-06-10 adversarial audit)

`generateBoard` is NOT self-certifying (its terminal fallback returns a best-effort board), so the contract lives in caller-side verification:

- **The Climb (C250):** certified from the marked Start-here opener at draw time; the builder returns only certified strictly-load-bearing boards or null. **Challenge matches:** dealt from the match library and re-certified from the STORED opener at install (`certifyStoredBoard`, ground-truth audit first), never generated under the click. **Daily/weekly:** certified from the board CENTER at precompute and on every load; the rendered "Start here" cell is a separately-searched certified full-solve anchor. Precompute/regenerate scripts THROW rather than write an uncertified canonical; the client strip-modifiers fallbacks verify (bounded retry) before shipping or writing; the post-tutorial warm-up board uses the certified generator. **First-click mine relocation was REMOVED 2026-06-12**: the board is FROZEN, a first-click mine is a bomb hit, the canonical never mutates.
- **The per-state honesty asterisk:** the certificate guarantees a no-guess PATH from the certified anchor, not that every reachable state is deduction-complete. Chaos is OUTSIDE the contract and labeled so in the UI.
- **Reveal gating:** sonar/compass/wormhole constraints are solver-usable only once their origin cell is revealed (wormhole: either endpoint). `gimmickConstraintVisible` in `boardSolver.js`; the gate's default comes from the board's own `board._gatedCert` flag, stamped by `createEmptyBoard`, carried by serialize/deserialize as `gatedCert`, and persisted with saves, so new boards certify gated while historical canonicals keep their ungated contract verbatim. Fetched canonicals are used VERBATIM; the client's load-time solve only feeds features/par/start-cell and never rejects the board.
- **Mystery is information-free and the solver enforces it:** `getPlayerVisibleCount` returns UNKNOWN(255) for mystery, `buildConstraints` skips 255, so certification is mystery-BLIND and conservative. `buildStaticGimmickConstraints` skips display-blocked cells (mystery + pressure plate) explicitly, so the solver is safe on its own terms (`test/mysteryConstraintGuard.test.mjs`, with a control that a plain wormhole pair still emits). Liar-stacked gimmick cells contribute NO range constraint.
- **Resolved holes, kept as rules:** magnetPull is EXTRACTION (mines removed entirely, information-monotone), never relocation. The locked-cell certifier auto-reveal oracle is gone: an unlocked cell must be PROVEN safe, and zero-valued cells act as Pass A constraint sources. Pressure plates are par-calibrated via `plateSeconds` (never below the classic rate, capped, rescales with every refit), a calibration, not a proof: the certificate still does not model wall-clock. Daily/weekly bomb strikes are information-monotone (mine preserved, numbers unchanged, strike = free flag); a revealed mine is modeled as a KNOWN MINE (sim=2) in `findDeducibleFrontier`.

## Board Topology (the solver is geometry-blind)

A board's adjacency is a GRAPH, not a geometry, and `src/logic/adjacency.js` is the single place that answers "what touches what". `buildNeighborCache(board, rows, cols)` returns the same shape for both declarations: **implicit** (the rectangular 8-neighborhood minus wall-severed edges) and **explicit** via `board._cellNeighbors`, stamped by `defineCellNeighbors` (which VALIDATES bounds, no self-loops, no duplicates, and above all SYMMETRY; an asymmetric list does not crash, it quietly certifies an unsolvable board). On an explicit topology, `rows`/`cols` are pure container indexing and walls never enter (a severed link is just absent).

Standing contracts, each with its story in the archive:

- **An explicit topology rides the game save as top-level `cellNeighbors`** (JSON.stringify drops array-stamped properties); `isSaveResumable` REJECTS a save whose topology fails validation, and `tryResumeGame` re-stamps through `defineCellNeighbors`.
- **`_wallEdges` keeps its `"r,c-r,c"` string format forever**: it lands in the signed bytes of every canonical and every save, and re-keying would silently UN-WALL every stored board (a lookup that finds nothing reads as "no wall"). Rejected explicitly by Christopher, 2026-07-19.
- **`buildTiling(type, M, N)` in `tilingGeometry.js` is the one dispatcher** (`TILING_BUILDERS`), and every builder emits the same descriptor shape. **An unrecognized type falls through to the 4.8.8 rather than throwing** (the generator's default depends on it), so any caller taking a type from OUTSIDE the code must validate against the exported `TILING_TYPES` first; a typo otherwise produces a plausible board on the wrong lattice with no error.
- **Corner-inclusive adjacency is the contract** (his rule 2026-07-27: "corners are adjacent in mine counts"), a structural no-op on 4.8.8 and honeycomb (both trivalent). Neighbor lists are sorted ascending because ORDER is load-bearing (`applyMirrorPairs` takes the first eligible neighbor). Valence check for a new tiling: sum over the cell's vertices of (deg(v) - 1), minus its side count.
- **Walls sever by SIGHT LINE, not by shared edge** (his rule 2026-08-07): if the center-to-center line between two cells is bisected by a wall, they are not connected. One test covers edge and corner neighbors; the certifier reads the same adjacency, so a violation here certifies internally-consistent-but-humanly-unsolvable boards, and the regression test asserts against the GEOMETRY a player sees. A failing wall chain is TRIMMED, never abandoned.
- **Vertex dedupe uses exact INTEGER lattice coordinates per builder** (`latticeVertices`), never rounded floats: a lost rounding bet splits a corner and drops adjacency silently, the one failure the no-guess contract cannot absorb. `assembleTiling` owns reading order (ascending centroid y then x, in builder units BEFORE normalization), the opener (nearest the center of mass, ties to the later cell), and normalization (inscribed diameter = one pitch for every isohedral tiling; the 4.8.8 keeps its own `OCT_CUT` tuning, so its two cell sizes are DERIVED at runtime, never hardcoded).
- **The compass needs per-lattice direction sets and, on cairo and deltoidal, a separate ray ANCHOR** (`COMPASS_DIRS_BY_TILING` in gimmicks.js; anchors in `cellPos.ax/ay`). Every anchor must be CLOSED FORM, never a numerical search (search error exceeds the colinearity EPS and silently shortens rays); `test/tilingCompass.test.mjs` re-measures every shipped set, its rotated alternative, and injects anchor noise. Display and certifier read the same STORED per-cell ray, so they can never disagree; `compassRay` is in `CELL_FIELDS` (dropping it made restored boards read 0 silently). Recompute a ray only from a `buildTiling` board: serialized `cellPos` drops the anchor.
- **The renderer derives a PER-CELL clip-path and box from the cell's own polygon** (`cellOutline`), because the Laves lattices place one shape in several orientations; box size does not identify rotation. The number draws at the cell's visual center via one-sided `_anchorPadding` (asymmetric cells); tiling cells zero `border-radius` AND `--cell-shape-radius` (a box radius eats clipped polygon tips). Tile SEAMS are DRAWN (`_renderTilingSeams`, from the same `buildWireframe` walls sever from; theme tokens `--tiling-seam-color`/`--tiling-seam-width`; z-index 2, under walls at 3). Keyboard focus on a tiling cell is an INSET wash plus a slight scale, never an outline (filter runs before clip-path). Wall/worm overlays map unit coords from `#board`'s content-box origin at the live `--cell-size`, never from cell 0's rect (cell 0's box width is not the pitch on the Laves lattices).
- **`layoutTilingCells()` re-lays inline pixel geometry on every pitch change** (called by `resizeCells`); re-laying rather than rebuilding preserves focus, animations, and overlay anchoring. Pinned by `tests/e2e/tilingResize.spec.mjs` across ALL tilings: the invariant is that the CELLS' painted extent stays proportional to the pitch, and per-cell clip-paths are byte-identical at every pitch.
- **A board may not be wider than a phone can hold** (`src/logic/boardFit.js`, 2026-08-06): reference phone 360x740 (his call), floors 28px for a board's majority cell class and 24px for a minority one (his verdicts). The pitch IS the tap target except on the 4.8.8 (ratios derived from shipped geometry at runtime). `boardFit.js` is the ONE definition; authored tables are held to it by `test/boardFit.test.mjs`; only chaos consults it at runtime (`chaosTilingDims` maximizes delivered PITCH under a comfort height). **The calibrator's candidate grid must be kept in step BY HAND**: a committed entry absent from the grid is measured but never proven. The Par Lab battery is deliberately EXEMPT (frozen played specs), and the test asserts the exemption stays real.
- **Rhombille has no Pass B** (its ladder runs Pass A straight to tank/gauss; its gate asserts `canonicalSubsetMoves === 0` explicitly) and is the generation-cost outlier; deltoidal is the second-dearest. Both are excluded from Chaos and carry per-shape endless generation caps.
- **Mine placement CONSTRUCTS above `CONSTRUCTIVE_DENSITY_THRESHOLD` (0.22)**: rectangles route `density > 0.22 || hasGimmicks` to `generateConstructive` (which takes an optional `topo`), while the tiling threshold is DENSITY-ONLY, deliberately unlike `generateBoard`'s `|| hasGimmicks` clause (revisit only if a modifier set turns up that fails under the threshold). The Laves lattices are weak BELOW it, so banded configs there set `constructive: true` (the `forceConstructive` per-call opt-in) rather than moving the shared constant, which would change every rectangular board. Rectangles are byte-identical through the constructive path and that is load-bearing (row-major candidate list, one rng() per candidate; golden fingerprints in `test/tilingConstructive.test.mjs`). The load-bearing filter applies to tilings with `TILING_LOAD_BEARING_BUDGET` (25) mirroring the daily's escape hatch; the ladder passes `loadBearingBudget: Infinity` and judges the result's `decorative` stamp.
- **Single-source region geometry:** `sonarScanCells` / `compassRayCells` (adjacency.js) feed BOTH `recomputeDisplayedMines` and `buildStaticGimmickConstraints`; drift between what the player SEES and what the certifier PROVES from is a silent no-guess hole (`test/adjacency.test.mjs` pins the equality). Sonar on a tiling is depth-2 GRAPH distance (exactly the 5x5 on an unwalled rectangle, pinned); rectangular boards keep the literal 5x5 with only the inner ring wall-severed (a design decision, not a refactor target; no shipped board has ever combined sonar with walls). `plateDisarmCells` is the plate's one demand region (live check + par estimator); its wall-BLINDNESS is deliberate and pinned while deduction and cascade respect walls. Wormhole pair separation on a tiling is GRAPH distance >= 3 (guarantees disjoint endpoint neighborhoods); the rectangular Manhattan branch is preserved VERBATIM because placement consumes the shared RNG stream. Power-up blasts: X-Ray = depth-2 corner-inclusive ball, Magnet = depth-1, Scan = the true horizontal + vertical LINES through the target (`scanLines`; his ruling: "not a blob"); rectangles keep their classic shapes verbatim. `recalcAreaAdjacency` (post-blast repair) derives its visit set from the neighbor cache, never the container 3x3.

## Board Solver Architecture

Two-layer solver guarantees no 50/50 guesses:

1. **Board solver** (`boardSolver.js`): simulates a full playthrough from first click, wall-aware. `getPlayerVisibleCount`: mystery/sonar/compass/wormhole return UNKNOWN (sonar/compass/wormhole contribute separate reveal-gated range constraints); liar returns UNKNOWN (`buildLiarConstraints` emits `{allowedMines: [X-1, X+1]}`); mirror returns the TRUE count (a smart player un-swaps; using `displayedMines` made boards spuriously unsolvable). Returns `{solvable, remainingUnknowns, totalClicks, techniqueLevel}` (0 Pass A, 1 subset, 2 tank/gauss, 3 disjunctive liar).
2. **Constraint solver** (`constraintSolver.js`): union-find partitions groups; constraints use `allowedMines: number[]` plus an `origin`. Tank (bitmask, <= 20 unknowns) handles disjunctive; Gaussian elimination beyond that, exact constraints only, and **sound-or-skip**: a row yields deductions only if every coefficient and the RHS snap to integers within 1e-6 (the rounding extraction fabricated verdicts on unsatisfiable systems; `test/gaussSoundness.test.mjs`). Gauss stays INCOMPLETE by design: a missed deduction is honest, a false one never is. `solveConstraints` also returns `groups`, `cellGroup`, and `contradiction` (a tank component with zero satisfying assignments = a provably wrong flag).

**Move classification:** five buckets at the `totalClicks++` sites (`passAMoves`, `canonicalSubsetMoves`, `genericSubsetMoves`, `advancedLogicMoves`, `disjunctiveMoves`); invariant: their sum + 1 === totalClicks. The model pools them into **pattern** (canonical + generic) and **search** (advanced) for identifiability; passA is dropped as a size proxy, disjunctive stays unmodeled.

**Deduction substrate** (the engine-as-witness layer): `isBoardSolvable(..., {trace: true})` returns per-reveal `{cell, tier, sources}` (collection-only; hot loops skip it; invariant `trace.length + 1 === totalClicks`). Pass C deductions count as disjunctive only if THEIR component carries a liar constraint. `findDeducibleFrontier(board, {respectFlags})` gives everything provable from live state; **every player-facing verdict must use the flags-blind run** (a wrong flag can poison the system into certifying a mine safe). `detectWrongFlags` is the dual-solve diff. `state.clickTimeline` records player actions (capped 2000, persisted) and is the only ground truth for player-grounded claims: never narrate the solver's order as the player's.

**Proof surfaces:** the post-loss Receipt paints the flags-blind frontier and answers "was this knowable?" per cell; daily/weekly wins get the one-line confession (crux + the modifier's CERTIFIED contribution tier from `gradeGimmickContribution`, so the copy can never overclaim); the Lens was REMOVED 2026-07-18, and two things deliberately SURVIVE it, never to be cleaned up: the refit's `filter(n_hints == 0)` and the `hintEvents` whitelist in both rules row families (a stale client can still submit one; an un-whitelisted child drops the whole write). The ✓ Certified chip renders from `state.boardCertificate` (`certificateFromCheck`; a failed solve must never stamp; chaos never stamps and shows "No guarantees") on the existing `#game-info-bar` row, never a row of its own (phone vertical space). **The stamp-witness map is fixed:** daily and weekly stamp the bestStart cell's OWN full-solve check (the chip claims "solvable without guessing from the marked start", so the center check that feeds features/par is the WRONG witness; no full-solve anchor, no stamp), challenge stamps the C250 builder's check at newGame, timed the accepted check from its first-click loop. The receipt confession and the par breakdown are suppressed for newcomer dailies (<= 3 plays). Reveal Safe is deduction-first (provably-safe cell, oracle only at a genuine frontier).

**Greg's voice** (`src/logic/gregVoice.js`, pure): Greg never says a number the engine can't prove; the bad days speak too; each surface renders once per session. The Daily field note derives from the CANONICAL board's stamped mission fields, NEVER by re-deriving the seed's slot against the current experimentTarget (boards pre-generate up to 7 days ahead; slot re-derivation names the wrong gimmick, the fieldnote-drift class).

**Greg's Journal** (`src/logic/journalFindings.js` + `journalProse.js` pure; rendered by `journalView.js` + `journalCard.js` + `journalFigure.js`): the nightly experiment's public notebook. THREE SECTIONS (his spec 2026-08-11): **Collecting data** (active hero + every ongoing study as rows with present-tense `statusLine` liners + the queue line), **Need to revisit** (reopened first with the amber Drifted chip, then widened, capped at `REVISIT_CAP` 3 with honest spillover: widened overflow rejoins collecting, reopened rejoins closed), **Closed for now** (the resting conclusions ledger). Every named study has a row; the table and `?report=` pages stay the deep route. The honesty rails that bind ALL notebook prose: zero em-dashes, max one hedge per sentence, digit honesty against the entry's fact object, day counts as "study day N", no player-behavior claims from a band, nothing ties a finding to today's board, measurement verbs on data sentences, complete sentences (the two sanctioned notations: lab-log datelines and ledger file stamps), estimates per TEN units via `featureScaleOf` (exp(10x) compounding, never 10x the per-unit percent), bounds spoken as 0% never "nothing", `fmtPct` whole percents. - **MISSION STEERING** (`src/logic/matchSteering.js`, 2026-08-12): a FEW of a match's slots prefer a board that also advances whatever study the refit is starved of. **The host's filter is the RULES and nothing reaches outside it** (his non-negotiable): `planMatchDeal` applies `eligibleRows` ITSELF, so a host who has not unlocked a shape never draws it however starved it is. At most `steeredSlotCap` = floor(N/5) boards steer (his ~20%), so a match of four or fewer is pure variety; **when nothing eligible advances anything, the deal is the ordinary deal and says nothing** (his "if no discovery can happen, that's fine"). Three things enforce his "it can't feel forced": one mission per steered slot in deficit order so two slots never double-sample one study (the daily's no-wrap rule), RANDOM tie-breaks among equal weights (several shapes sit at 0 boards early, and a fixed order would send every steered slot in the world to whichever sorted first), and a shuffle of the WHOLE dealt list so a steered board is equally likely at any position. The seen-cycle is untouched: a steered pick reaches the seen remainder only inside the budget the deal was going to spend there anyway, and `cycled` is computed from the full eligible set so it means exactly what it meant before. **The index bounds what steering can SEE**: rows carry shape and modifier PRESENCE, never the feature vector, so shape-coverage and gimmick-presence missions are reachable and feature-level ones are not (the digit shares are observational anyway, and the decorrelation mission's residual needs the same missing column; carrying all four would grow the index 37 KB to 61 KB, measured, on a file every host fetches, so widening it is HIS call). ## Greg-par Model (Daily)

Daily par is a **log-linear multiplicative regression** (`PAR_MODEL` carries `scale: 'log'`): par = exp(intercept + sum coef x feature), the lognormal median, so each coefficient is a log-multiplier, never seconds. Coefficients are stored between refit markers in `src/logic/difficulty.js`; the model logic in `src/logic/dailyFeatures.js` (`computeDailyFeatures`, `predictPar`, `breakdownPar`). **Move type is the primary signal**, pooled into pattern + search tiers for identifiability. The STORED feature vector (dailyMeta) keeps raw counts unchanged; model predictors DERIVE from it via `COEF_TERMS`, one source of truth the R refit mirrors. The end-of-game breakdown allocates above-baseline seconds by log-share so chips still read in seconds.

**Per-shape par: one JOINT fit with signed deviations, never six fits** (the player random intercept must be estimated jointly, or the shapes would ship disagreeing handicaps). `PAR_MODEL_SHAPES` (refit-owned markers in difficulty.js) carries one composed coefficient set per tiling; `modelFor(features)` dispatches: `modeTimed` first (a retired path since Quick Play was absorbed, kept because stored rows carry the key), then `tilingType`, then `PAR_MODEL`, which is also the SILENT fallback for an unknown type, so outside-code types must validate against `TILING_TYPES` (and the `'6.6.6'` deep-link alias is normalized by `modelFor`, **never a block key**). `scripts/calibrate-today.mjs` is the pre-ship scale anchor: regenerate today's board locally and check `predictPar` lands inside the observed completion range before shipping new coefficients. Priors: the 18 core deviations center on the Par Lab posteriors at doubled width from the frozen `scripts/data/parlab-prior-centers.json` (loader fails SOFT; the contract test then fails LOUD, pinning block-minus-base against the lab JSON). Sampling is TWO-PATH by construction (flat formula with the lb=0 blanket when no deviation column is active; a brms non-linear split when one is: the bound is a transform statement, and removing it collapsed a clean fit into divergences). Lab-seeded core terms ship fitted posteriors with no 20-row wait and lab CENTERS with zero live rows; unseeded terms keep the `NEW_FEATURE_DATA_THRESHOLD` (20) earn guard. Deviations ride modelHistory as `shapeDeviations`, never `target_candidates`. The digit frame is rectangles-only (with lattice rows in the frame, the digit coefficients become part-shape indicators). **`tilingType` is DERIVED from the board and ABSENT on rectangles** (never 'rect', never 0: the sweep's vintage hatch is `stored === undefined && recomputed === 0`); a new tiling is a new VALUE, never a new key, so `FEATURES_EPOCH` does not move for one. **The hand-maintained sprintf emitters are GONE**: all three model blocks are emitted by one generator driven by `COEF_TO_PREDICTOR` and `SHAPE_TABLE` (adding a coefficient is one table entry plus its prior); the contract test asserts the templates stay dead and the emitter region reproduces the committed difficulty.js byte for byte.

## Par Bands (daily/weekly difficulty distribution)

**His ruling (2026-08-02): every daily lands at par in [20, 240]s, every weekly in [60, 360]s, skewed easy with occasional hard boards.** The shape is the "hard-day coin": 85% easy Beta(2,5), 15% hard Beta(2,2) on the upper span; the easy hill stays anchored where he approved it (`easyHi`/`hardLo`). **One source: `src/logic/parBand.js`** (leaf; in the typecheck set and the sw precache), consumed by both sides of both mirror pairs. Draws are deterministic from the date string alone in distinct namespaces (`:parTarget` / `:weeklyParTarget`, distinct BECAUSE a weekStart is a Monday date string); exactly two rng() calls per draw; closed-form polynomial CDFs, engine-stable. ## Modifier (Gimmick) System

11 types in `src/logic/gimmicks.js`; "Gimmicks" in code = "Modifiers" in ALL player-facing text. Daily-safe subset: mystery, locked, walls, liar, wormhole, mirror, sonar, compass, worm (the bar: board DATA static and canonical). Standing contracts:

- **First-encounter cards are tracked BY REVISION, not by name** (his ruling): the seen-set stores an FNV-1a hash of the card's own player-visible content, so any copy edit re-shows the card with nothing to remember to bump; a correction must reach exactly the people carrying the wrong idea. The shape seen-set works the same way over the drawn patch.
- **Per-cell stacking** (enforced in `applyGimmicks`): base-value gimmicks (wormhole, mirror, sonar, compass) mutually exclusive; liar stacks on any base value; locked stacks with base + liar; mystery and pressure plate fully exclusive; worm eggs only on PLAIN numbered safe cells, and `applyWorm` runs LAST in `ORDER`. Hidden eggs render as normal cells (a telegraphed egg would leak safety).
- **Worm Tiles:** information is DELAYED, never destroyed; **the solver is entirely worm-blind**, which is the whole reason worm is daily-safe. Worm length and lifetime are deterministic per egg from the seed identity (every player hatches identical worms; only the walk is luck); the crawl is side-only on tilings via `buildWormCrawlTopology` (proven no-op on the trivalent pair) at a SET per-worm pace (`WORM_MOVE_BASE_MS` x a per-egg pace trait); movement has momentum, number-aversion on TRUE counts, and near-no backtracking. Par feature **`wormLoad`** = sum(length x lifetime x pace)/100, the SCHEDULED dose; the FIT uses each row's REALIZED dose from `state.wormEvents` (fitting the schedule would attenuate: fast solvers realize less of it), bridged by the play-weighted realization ratio since predictPar can only know the schedule. Worm is the first sprite-only modifier (no `icon`; every `def.icon` consumer needs a missing-icon guard). Worm tones are mixed in JS (`mixHex`), **never CSS color-mix** (a var-dependent color-mix on an older engine computes to no background: an invisible worm). **A per-tiling branch whose DEFAULT is the 4.8.8's special case will be wrong for the next lattice, silently** (the `wormSegmentSize` lesson): defaults must be the general case, and the pins walk `TILING_TYPES` so a seventh tiling is covered the day it is registered. `gradeGimmickContribution` grades worm `structural`.
- **Displayed-number source of truth:** `recomputeDisplayedMines(board)` is the ONE writer of `displayedMines`, called at the end of `applyGimmicks` and after any mine-layout change.
- **Adjacency source of truth:** `adjacency.js` (leaf) owns wall keys and neighbor caches; `countAdjacentMines`/`recalcAllAdjacency` in gimmicks.js are the ONE mine counter (**a mine's `adjacentMines` is ALWAYS 0**, the convention four drifted copies once disagreed on). Pass a cache to `countAdjacentMines` from any loop or an O(cells) sweep goes O(cells^2). The sanctioned scoped exceptions: `placeMineIncremental`/`removeMineIncremental` and cruxExtract's mini recompute.
- Mirror is a 2-cell adjacent swap (cells store `mirrorPair`). `applyWalls` ALWAYS calls `recalcAllAdjacency`, even when the isolation check clears walls (stale wall-aware counts otherwise); `applyGimmicks` skips re-rolling walls when `board._wallEdges` is pre-populated (challenge pre-applies). Wall overlays are pixel-anchored to live cell rects: every path that moves cells re-renders them (resize handler + theme refit).

## Theme System

**26 kept themes; the count is FROZEN** (the feel budget deepens these, never adds palettes). Unlock ladder: classic + dark free; the rest at L25 then one every 10 levels to L250 (every unlock ON a checkpoint; Legendary on the crown; themes fully relock at the C250 reset since unlocks derive from maxLevelReached). `test/themeUnlockLadder.test.mjs` enforces the structure; restoring a cut theme means a ladder slot, bumping everything after it. Standing contracts:

- **Every default in the expression-token layer equals the old literal**, so a theme that overrides nothing renders byte-identically; the frozen computed-style probe (`scripts/theme-style-probe.html`) is the committed verification tool (pause animations, never `animation: none`; cache-bust per run).
- `--cell-min/max-size` + `--cell-fit-max-size` are read by JS (`resizeCells`), the only way a theme can bound cells; both fitters read the live `--grid-gap`, and `applyThemeLive` re-runs `resizeCells` after the lazy stylesheet actually loads.
- **Grout-contrast HARD RULE, absolute:** any effect-bearing theme must set `--cell-gap-seal` to visibly CONTRAST `--color-cell-revealed`; grout == tile is the banned slab (his rejection is verbatim in the archive). The gap-seal excludes the face-cue markers (mirror's dashes were buried once); colorblind mode is the one sanctioned seal exception.
- **Special-cell legibility HARD FLOOR:** markers may be re-hued only to avoid the theme's own background; identity anchors in a non-color channel; line markers >= 3:1 contrast; tints >= 0.12, borders >= 0.6; markers keep `!important`. **`--color-wall` has its own higher floor: >= 3.5:1 against BOTH cell backgrounds** (revealed AND hidden); where no single color can clear both, `.wall-line` supports a two-tone wall (`--color-wall` body + `--color-wall-outline` ring), and the floor becomes: each background cleared by body OR outline.
- **Effects:** `.theme-fx` sits at z-index 1 (under revealed cells at 2, walls at 3); `applyThemeEffects` early-returns under `prefers-reduced-motion` or software rendering (`isSoftwareRenderer`, node-tested; unknown renderer strings are conservatively NOT software). Effects are vector-drawn, never emoji particles. Num colors 9-20 exist for wormhole sums (19-20 for tiling valences); dark themes override them bright.
- **Per-theme objects + moments contract:** objects live in `THEME_UNLOCKS` emoji fields resolved by `getThemeEmoji`; drawn sprites swap in via `THEME_SPRITES` in `spriteLoader.js`, rendering ONLY when the resolved emoji equals the theme's own (the identity contract). A new theme supplies at minimum objects + contrasting grout (if effect-bearing) + a confetti palette entry (keyed by `state.theme`: a palette under a stale key silently never fires). Audio: `THEME_SOUND_PALETTES`, every non-classic theme voiced; classic is deliberately paletteless (the default synth IS its identity); `test/themeSoundPalettes.test.mjs` gates shape, loudness, key integrity, and pairwise distinctness.
- Grandfathered carve-outs (do not "fix" blindly): gradient-clip titles, modal backdrop blur, Orbitron/Fredoka as real display fonts, the two parallel timer color systems (both read the tokens).

Rate limits: 30s cooldown per submission path (each path its own clock); a daily submission inside its own cooldown QUEUES; retry queues resolve the uid at FLUSH time. Score validation 5-3600s.

**Database paths and their contracts:** `daily/{date}/{pushId}` (append-only score rows; `rngSeed` omitted when it equals the dateString, reconstruct via `effectiveRowSeed`; `hintEvents` is a RETIRED field whose whitelist deliberately survives), `dailyArchive/`, `parLab/` (the one un-test-gated writer, see Board Topology), `dailyMeta/{date}` (write-once features), `cruxes/{date}` (write-once, `".write": false`, service-account writer only), `boardHeatmap/{date}` (same posture), `dailyBoard/{date}` + `weeklyBoard/{weekStart}` (write-once canonicals), `users/{uid}/...` (owner-scoped progress; the node ends `$other: false`, so EVERY new child needs a whitelist entry or the whole progress write drops silently, the 866683d class), `weekly/{weekStart}/{uid}` (one row per player, **set, not push**) and `users/{uid}/weeklyAttempts/...` (the attempt cap), `users/{uid}/friends/{friendUid}` (owner-only READ, and a DELIBERATE write exception: a stranger may write/delete ONLY the entry keyed by their own uid, `auth.uid === $friendUid`, which is why one code redemption serves BOTH sides; Cloud streak merges are date-anchored (newer date adopts verbatim, same date takes the higher, older keeps local).

## Leaderboard Name Filtering (hate speech)

Scope is hate speech ONLY, not general profanity (false positives near zero). Client reject: `setPlayerName` calls `containsHateSpeech` (normalize, leetspeak map, substring over `HATE_SPEECH_TERMS_CLIENT_SAFE`, the low-collision subset). Server sweep: `scrub-leaderboard-names.mjs` (3-hourly) uses the UNION of `obscenity` (boundary-aware, fuller `HATE_SPEECH_TERMS` list) and the client normalizer, scrubbing to "Anonymous" (replace, never delete) across every name-bearing path; `test/scrubCoverage.test.mjs` DERIVES that path set from the rules file so a new name-bearing path cannot ship unswept. **`matches/` is swept even though the derivation EXEMPTS it** (its read is expression-gated, the friendCodes shape): the read posture keeps matches from being enumerated, and says nothing about whether the names inside are shown to people, which they are. The sweep also deletes expired `matchCodes/` at the 7-day window, which matters more than the friend-code tidiness sweep because a week of dead codes accumulates at a time. **NEVER feed the fuller list to a naive substring matcher.**
