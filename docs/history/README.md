# CLAUDE.md history archive

CLAUDE.md carried the project's whole chronicle until 2026-08-11, about 64,000 words, most of it incident narratives, measurements, and dated arcs rather than operating rules. Those sections were moved here VERBATIM on that date; CLAUDE.md keeps the distilled operative layer (contracts, invariants, single-source locations, standing rulings) plus a pointer into this directory from each section.

Two rules for reading and writing here:

- CLAUDE.md is the source of truth for any CURRENT fact. If a file here disagrees with it, the file is describing the past.
- These files are an archive, not documentation to maintain. New history accumulates in the file matching its topic; nothing here needs updating when the code moves on, because each file states its as-of date.
