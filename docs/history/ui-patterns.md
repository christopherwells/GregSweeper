## Important Patterns

- **DOM structure:** `#title-screen` is a sibling of `#app`, not inside it. Modals are inside `#app`, when `#app` has `.hidden` class (display: none), child modals can't render. Modals that need to show on title screen must be outside `#app`.
- **Title screen layout (2026-06-12 grouping; heroes 2026-08-10):** six mode cards, **Daily and Weekly lead as full-width HEROES** (`.mode-card-hero`), then The Climb, Quick Play, Chaos and Greg's Gym in the 2-column grid below (the Gym card has no `data-mode`, it opens the lesson overlay). An odd visible count among the GRID cards spans the last card full-width since locked Chaos hides its card, counted by `updateTitleProgress`, which toggles `.odd-cards` on the grid, because the hidden Chaos card keeps its `:nth-child` slot and a pure-CSS odd test can't see it. **The heroes are excluded from that count** (they always span, so they can never be the orphan); with exactly two heroes the parity is unchanged either way, which is why the exclusion is written down rather than relied on. A hero turns its content on its side, icon beside the text instead of above it, and takes the **Past chip into the grid as a real item** (`grid-template-areas: "icon name past" / "icon note note"`) rather than leaving it an absolute corner: on a hero the note's first line reaches the top-right, measured on neon. That also frees the hero's own padding, which is where the extra grid row is paid for; measured at 360x630 (the reference phone with browser chrome showing) the six-card front door is SHORTER than the pre-hero one (fits with 18px spare where the flat grid had 11, and 7px of scroll vs 14 with Chaos unlocked). The hero band (`padding-bottom`) must clear the TALLEST theme's stat line, chalkboard's Comic Sans runs ~3px taller than classic's at the same font-size, and 20px put the note over the streak there. Footer: a three-button footer: How to Play, Progress (`#progress-sheet`: Stats / Achievements / Leaderboard), More (`#more-sheet`: Collection / Settings / Greg's Journal / What's New). Sheet rows call `hideModal(sheet)` then the destination's prep + `showModalFromTitle`, plain hideModal so `_returnToTitle` survives the hop and the destination's close returns to the title. The What's New NEW badge rides the sheet row; `#more-btn-dot` on the More button shows the signal while the sheet is closed. The Modifiers help tab is rendered from `getGimmickDefs()` at boot (`#help-modifier-list`) so the reference can't drift.
- **`_returnToTitle` flag** in `src/ui/titleScreen.js` tracks when modals were opened from the title screen (set via `showModalFromTitle`, consumed by `closeModalAndReturn`; `setReturnToTitle(false)` for entering-a-game paths).
- **`$()` / `$$()`** are querySelector/querySelectorAll helpers from `src/ui/domHelpers.js`.
- **"Gimmicks" in code = "Modifiers" in player-facing UI.** Always use "Modifier" in user-facing text.
- **Daily mode** uses seeded RNG (`createDailyRNG(dateString)`) for deterministic boards per date.
- **`CURRENT_VERSION`** in main.js drives the "What's New" badge: first load after an update shows a NEW badge on the title-screen What's New button; the modal opens on click (it does NOT auto-open).
- **`generateBoard` calls `cleanSolverArtifacts`** on every return path (solver leaks `isRevealed` onto cells).
